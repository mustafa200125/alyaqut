<product_requirements>
The project is to build a full-stack social media application called الياقوت (The Ruby), featuring a modern, ruby-colored aesthetic.

**Core Features Implemented:**
-   **User Authentication:** Secure registration and login via email and password. Verification is handled by displaying a code in the UI, bypassing the need for email integration.
-   **User Profiles:** Customizable profiles where users can set a profile picture (with cropping), bio, gender, country, city, and profession. Email is visible only to the profile owner.
-   **Social Graph:** Users can follow/unfollow, send/accept/cancel friend requests, and block/unblock other users. Blocked users' content is hidden throughout the app.
-   **Content & Feeds:** Users can create and view posts. The main feed displays posts from followed users. An AI-powered feature suggests post ideas.
-   **Advanced Messaging:** Real-time one-on-one chat with features including:
    -   Voice and video calls (WebRTC).
    -   High-quality image (up to 50MB) and video (up to 500MB) sharing.
    -   Voice messages (Bismat) with a dedicated recording UI and audio player.
    -   A shared YouTube player where users can co-watch videos by pasting a URL.
-   **Branding:** The application uses a custom user-provided image as its logo and favicon.
</product_requirements>
